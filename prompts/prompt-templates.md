# 자주 쓰는 프롬프트 모음

학습 효율을 높이는 프롬프트 템플릿. 복사해서 쓰세요.

## 🔤 표현 학습

```
[표현]을 알려줘. 
- 비즈니스/일상 중 어느 쪽에 더 맞아?
- 혼동하기 쉬운 표현도 같이
```

```
[표현1]과 [표현2]의 차이가 뭐야? 언제 어떤 걸 써야 해?
```

```
"[한국어]" 이 뉘앙스에 가장 맞는 영어 표현 3개 추천해줘. 각각 언제 쓰는지도.
```

## 💾 정리 요청

```
방금 설명한 거 [시트명] 시트에 정리해줘.
```

```
예문만 하나 더 추가해서 저장해줘. situation은 "친구에게 부탁할 때"로.
```

```
방금 대화에서 나온 표현 3개 전부 [시트명] 시트에 한 번에 저장해줘.
```

## 📖 복습

```
[시트명] 시트에서 지난 일주일에 추가한 표현으로 퀴즈 10개 내줘.
한국어만 보여주고, 내가 답하면 채점해줘.
```

```
[시트명] 시트 최근 20개 중에 내가 아직 자신 없는 표현 골라서 
새 예문으로 문제 만들어줘.
```

```
[시트명] 시트에 쌓인 표현들로 자연스러운 영어 대화 스크립트 
하나 만들어줘. 내가 방금 배운 표현 위주로.
```

## ✍️ 쓰기 교정

```
아래 영어 문장 자연스럽게 고쳐줘. 내 의도는 [...]야.

[문장]
```

```
이거 원어민이면 어떻게 말할까? [상황 설명]
```

## 🗂 시트 관리

```
내 시트 뭐뭐 있어?
```

```
[시트명] 시트 전체 몇 개 있어? 최근에 추가한 5개만 보여줘.
```

```
[표현] 이거 어느 시트에 있었더라?
```

## 💡 응용

```
이번 주 [시트명] 시트에 추가한 표현으로 짧은 글 써봐. 
그럼 내가 너가 쓴 거 보면서 맥락을 익힐 수 있어.
```

```
내가 최근에 저장한 표현들 보면, 내가 부족한 영역이 뭘까?
다음 주에 중점적으로 공부하면 좋을 주제 추천해줘.
```
